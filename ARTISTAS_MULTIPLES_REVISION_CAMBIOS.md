# Artistas múltiples en revisión

- La detección de artista solicita una hipótesis principal y entre 2 y 4 alternativas plausibles cuando existan versiones conocidas.
- Las alternativas se ordenan por confianza, se deduplican y no repiten el artista principal.
- En la pantalla «Revisa los cambios propuestos» se muestra el artista detectado por la IA.
- El usuario puede elegir otra interpretación sugerida desde un selector.
- Se agregó «Indicar otro artista» para escribir manualmente un nombre diferente.
- Al cambiar el artista se vuelve a comprobar si la combinación título + artista ya existe.
- El encabezado de la versión estructurada muestra el artista actualmente seleccionado.
