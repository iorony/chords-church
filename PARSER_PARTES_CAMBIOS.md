# Reconocimiento de PARTES y encabezados en texto plano

Se agregó soporte local y para el enriquecimiento con IA de encabezados como:

- INTRO / INTRODUCCIÓN
- PARTE I, PARTE II, PARTE III, etc.
- SOLO DE GUITARRA / SOLO DE PIANO
- FINAL / FIN / CIERRE
- SALIDA / OUTRO

Las etiquetas `PARTE` se conservan como tales y no se convierten automáticamente en `ESTROFA`.
