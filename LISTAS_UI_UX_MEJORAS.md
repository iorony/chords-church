# Mejoras UI/UX de Mis listas y detalle de lista

- Portada visual para "Mis listas" con métricas de listas, confirmadas y canciones.
- Tarjetas de repertorio con estado, fecha, lugar, cantidad de canciones y visibilidad.
- Estado vacío con llamada clara para crear la primera lista.
- Formulario de nueva lista rediseñado y responsive.
- Encabezado contextual dentro del detalle de lista.
- Acciones principales uniformes para presentar, exportar PDF/DOCX y confirmar.
- Canciones ordenadas en filas táctiles con controles de tono y reordenamiento.
- Feedback visual al guardar tonalidades y agregar canciones.
- Buscador y favoritas reorganizados en paneles claros.
- Mejoras responsive para escritorio y móvil.
