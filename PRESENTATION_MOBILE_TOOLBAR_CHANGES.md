# Barra inferior móvil en modo presentación

- Barra flotante inferior exclusiva para móvil: ◀ · A− · A+ · ⛶ · ▶.
- El contenido reserva espacio para la barra y respeta `safe-area-inset-bottom`.
- Anterior/Siguiente cambian de canción y mantienen el retorno automático al inicio.
- A−/A+ cambian conjuntamente secciones, letra, acordes y título.
- El tamaño elegido se conserva en `localStorage`.
- Pantalla completa entra o sale mediante Fullscreen API.
- Los controles superiores completos se mantienen únicamente en escritorio.
